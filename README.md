# 🖥️ Sahoo OS

A retro desktop-inspired portfolio built with **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS**. Instead of navigating traditional web pages, visitors interact with a desktop operating system featuring draggable icons, resizable windows, a terminal, desktop widgets, and a modern glassmorphism interface.

![Sahoo OS Banner](./public/pixel/charecterrr.png)

---

## ✨ Features

- 🖥️ Interactive desktop environment
- 🪟 Draggable & resizable windows
- 📁 Desktop-style application launcher
- 👤 Profile window
- 💼 Projects explorer
- 💻 Interactive terminal
- 📄 Resume download
- 📬 Contact window
- ⏰ Live desktop clock widget
- 📶 Network widget
- 🔋 Battery indicator
- 🔊 Volume indicator
- 📱 Responsive design
- 🌙 Modern glassmorphism UI
- ⚡ Optimized with Next.js App Router

## ⚙️ Installation

Clone the repository.

```bash
git clone https://github.com/jyotiranjansahooo/sahooOS.git
```

Go into the project.

```bash
cd sahoo-os
```

Install dependencies.

```bash
npm install
```

Run the development server.

```bash
npm run dev
```

Open

```
http://localhost:3001
```

---

## 🏗️ Production Build

```bash
npm run build
```

Start production server.

```bash
npm start
```

---

## 🌐 Deployment

The project is optimized for deployment on **Vercel**.

```bash
git add .

git commit -m "Initial Release"

git push origin main
```

Import the repository into Vercel and deploy.
